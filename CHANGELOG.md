# Changelog

## 0.1.0 - 2026-10-13

- Geometric six-joint Kinova Gen3 mechanical model using pinned manufacturer link data.
- Relative-frame RNEA, space/body twists, adjoints and product-of-exponentials kinematics.
- Configurable diagonal apparent actuator inertia using the documented Cholet proxy convention.
- Passive smoothed viscous/Coulomb friction using the published Muraccioli coefficients.
- Preserved SHAPE optimized kernels and Flatness-MPC scalar trajectory functions.
- Independent mechanical validation, matched CPU benchmark and integration refinement checks.
- Standalone MATLAB example, official visual meshes, animation and saved test receipts.
- MIT new-code license with preserved third-party notices and source hashes.
